## 设置应用权限

以下是在 **Android 手机上为 CRM 自动拨号软件设置“电话”和“发送短信”权限** 的通用操作步骤（适用于 Android 8.0 及以上主流版本，如 MIUI、ColorOS、EMUI、Samsung One UI 等）：

### 📱 CRM 自动拨号软件权限设置指南

:::tip
 **适用场景**：首次安装 CRM 拨号类 App 后，无法自动拨号或发送短信，需手动授权。
:::

#### 步骤 1：进入系统「设置」
1. 解锁手机，点击 **「设置」**（齿轮图标）。

#### 步骤 2：进入「应用管理」或「应用」
2. 向下滚动，找到并点击：
   - **「应用」**（三星、原生 Android）
   - **「应用管理」**（华为、小米、OPPO、vivo 等）
   - 部分品牌可能叫 **「应用列表」** 或 **「已安装应用」**

#### 步骤 3：找到你的 CRM 应用
1. 在应用列表中，找到你安装的 **CRM 自动拨号软件**。
   - 可使用顶部搜索框输入应用名称快速查找。

#### 步骤 4：进入「权限管理」
4. 点击该应用名称，进入应用详情页。
5. 找到并点击 **「权限」** 或 **「应用权限」**（不同品牌位置略有差异）。

#### 步骤 5：开启关键权限
6. 在权限列表中，依次找到并设置以下两项为 **「允许」**：
   - ✅ **电话**（用于自动拨号、读取通话状态）
   - ✅ **短信**（用于发送短信验证码或通知）

   > ⚠️ 注意：  
   > - 某些手机（如小米、华为）可能将“短信”权限命名为 **「发送短信」** 或 **「短信/彩信」**。  
   > - 若看到 **「通话记录」** 或 **「读取联系人」** 权限，也建议一并允许。

#### 步骤 6：（可选）关闭电池优化（防后台被杀）
7. 返回应用详情页，点击 **「电池」** 或 **「省电策略」**。
8. 选择 **「无限制」** 或 **「不优化」**，防止系统在后台杀死 CRM 应用导致拨号失败。

#### 步骤 7：返回并测试
9. 返回桌面，重新打开 CRM 软件，尝试自动拨号或发送短信功能，确认是否正常工作。

### 🔒 常见品牌路径参考

| 品牌 | 权限设置路径简写 |
|------|------------------|
| **小米（MIUI）** | 设置 → 应用设置 → 应用管理 → [App] → 权限管理 |
| **华为（EMUI）** | 设置 → 应用 → 应用管理 → [App] → 权限 |
| **OPPO/一加（ColorOS）** | 设置 → 应用 → 权限管理 → [App] |
| **vivo/iQOO（OriginOS）** | 设置 → 应用与权限 → 权限管理 → 应用权限 |
| **三星（One UI）** | 设置 → 应用 → [App] → 权限 |

---

:::tip
如果 CRM 软件仍无法拨号，请检查是否被系统“安全中心”或“手机管家”限制了后台活动，需在对应安全软件中将 CRM 应用设为 **“允许后台运行”** 和 **“允许自启动”**。
:::

完成以上设置后，CRM 自动拨号与短信功能即可正常运行。
