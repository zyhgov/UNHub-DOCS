本文系统梳理了当前全球范围内主流的 AI/大语言模型（LLM）、核心提供商及其代表性应用，涵盖开源与闭源模型、企业与研究机构、工具平台与终端产品。

:::info
**大语言模型 LLM**（Large Language Model，简称LLM）是通过在大量文本数据上进行训练的深度学习模型。这些模型能够理解和生成自然语言，执行多种任务，如文本生成、翻译、问答、情感分析等。LLM的核心在于其庞大的参数量和复杂的结构，通常包含数十亿个参数，这使得它们能够学习语言中的复杂模式和关系。
:::
