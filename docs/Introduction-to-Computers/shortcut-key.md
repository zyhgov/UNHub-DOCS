# Windows 系统全局快捷键

- Windows 系统本身（包括不同版本如 Win10、Win11）内置数百个快捷键；
- 不同应用程序（如 Word、浏览器、IDE）会定义自己的快捷键；
- 第三方软件、输入法、显卡驱动、厂商工具（如 Dell、联想快捷键）也会添加自定义组合；
- 某些快捷键依赖于键盘布局（如美式、中文、Fn 键行为）或硬件（如带 Win 键的键盘）；
- 还有可由用户自定义的快捷方式（如通过 AutoHotkey、PowerToys 等）。

本文此处 **系统性地整理 Windows 操作系统中最常用、最核心、覆盖全局的官方快捷键（适用于 Windows 10 / 11）**，按功能分类，力求“**全面而实用**”。

## 🪟 Windows 10 / 11 通用

### 🔤 通用操作
| 快捷键 | 功能 |
|--------|------|
| `Ctrl + C` | 复制选中内容 |
| `Ctrl + X` | 剪切选中内容 |
| `Ctrl + V` | 粘贴 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
| `Ctrl + A` | 全选 |
| `Ctrl + S` | 保存 |
| `Ctrl + P` | 打印 |
| `Ctrl + F` | 查找 |
| `Ctrl + N` | 新建窗口（文件资源管理器、浏览器等） |
| `Ctrl + W` | 关闭当前标签页或窗口 |
| `Ctrl + T` | 新建标签页（浏览器、终端等） |
| `Ctrl + Shift + T` | 恢复刚关闭的标签页 |
| `Alt + Tab` | 切换打开的应用程序（带预览） |
| `Alt + F4` | 关闭当前窗口 / 弹出关机菜单（桌面时） |
| `Win + D` | 显示桌面（再按一次恢复窗口） |
| `Win + L` | 锁定计算机 |
| `Win + E` | 打开文件资源管理器 |
| `Win + R` | 打开“运行”对话框 |
| `Win + I` | 打开“设置” |
| `Win + A` | 打开操作中心（通知与快速设置） |
| `Win + S` 或 `Win + Q` | 打开搜索（Win11 中为搜索/聊天） |
| `Win + Tab` | 打开任务视图（虚拟桌面 + 窗口预览） |
| `Print Screen` 或 `PrtScn` | 截取全屏并复制到剪贴板 |
| `Alt + Print Screen` | 截取当前活动窗口 |
| `Win + Shift + S` | 启动截图工具（矩形/自由/窗口/全屏） |
| `Win + V` | 打开剪贴板历史（需在设置中启用） |
| `Win + .` 或 `Win + ;` | 打开表情符号面板（含符号、颜文字、emoji） |

### 🖥️ 窗口管理
| 快捷键 | 功能 |
|--------|------|
| `Win + ← / →` | 将窗口贴靠到左/右半屏 |
| `Win + ↑` | 最大化窗口 |
| `Win + ↓` | 最小化窗口 / 还原最大化窗口 |
| `Win + Home` | 最小化/还原除当前窗口外的所有窗口 |
| `Win + Shift + ← / →` | 将窗口移动到相邻显示器（多屏时） |
| `Win + M` | 最小化所有窗口 |
| `Win + Shift + M` | 恢复最小化的窗口 |
| `Alt + Space` | 打开当前窗口的系统菜单（可移动、大小、最小化等） |
| `F11` | 全屏切换（浏览器、部分应用） |

---

### 💻 虚拟桌面（多桌面）
| 快捷键 | 功能 |
|--------|------|
| `Win + Ctrl + D` | 新建虚拟桌面 |
| `Win + Ctrl + ← / →` | 切换虚拟桌面 |
| `Win + Ctrl + F4` | 关闭当前虚拟桌面 |
| `Win + Tab` → 点击“新建桌面” | 图形化创建（非快捷键，但常用） |

### 🛠️ 系统与工具
| 快捷键 | 功能 |
|--------|------|
| `Win + X` | 打开高级用户菜单（电源、任务管理器、磁盘管理等） |
| `Ctrl + Shift + Esc` | 直接打开任务管理器 |
| `Win + P` | 切换投影模式（仅电脑、复制、扩展、仅第二屏幕） |
| `Win + K` | 打开无线投屏/蓝牙设备面板（Win10 1803+ / Win11） |
| `Win + U` | 打开“轻松使用”设置（辅助功能） |
| `Win + Pause` | 打开“系统属性”（关于本机） |

### ⌨️ 键盘与输入
| 快捷键 | 功能 |
|--------|------|
| `Shift`（按5次） | 启用/禁用粘滞键（需在设置中开启提示） |
| `Ctrl`（按住8秒） | 启用/禁用筛选键 |
| `Win + Space` | 切换输入法 / 键盘布局 |
| `Win + Ctrl + Space` | 临时切换回上一个输入法 |
| `Alt + Shift` | 传统输入法切换（若未被 Win+Space 替代） |

---

### 🌐 浏览器通用快捷键（Chrome / Edge / Firefox）
| 快捷键 | 功能 |
|--------|------|
| `Ctrl + R` / `F5` | 刷新页面 |
| `Ctrl + Shift + R` / `Ctrl + F5` | 强制刷新（忽略缓存） |
| `Ctrl + L` / `Alt + D` | 聚焦地址栏 |
| `Ctrl + H` | 打开历史记录 |
| `Ctrl + J` | 打开下载记录 |
| `Ctrl + Shift + Delete` | 打开清除浏览数据面板 |
| `Ctrl + Shift + N` | 打开无痕/隐私窗口 |
| `Ctrl + [1-8]` | 切换到对应编号的标签页 |
| `Ctrl + 9` | 切换到最后一个标签页 |

### 💡 补充说明
- **部分快捷键在不同国家/地区键盘上可能不同**（如某些欧洲键盘无 Win 键，或 Fn 键需配合使用）。
- **游戏模式或全屏应用可能拦截快捷键**。
- **Windows 11 对部分快捷键做了调整**（如 `Win + S` 不再是纯搜索，可能打开 Copilot）。
- **PowerToys（微软官方工具）可自定义快捷键、增强窗口管理**（如 FancyZones）。
