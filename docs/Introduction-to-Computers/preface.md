# 💻 人人都会使用计算机

![人人都会使用计算机](img/how-it-works-diagram.webp)

## 没门槛？好懂？还有点干货？

这本书，说白了，是给那些看到“右键单击”就冒汗、以为“下载”真能从天上掉东西下来的“不懂电脑”写的——也就是你我这样的凡人。

它不讲什么二进制玄学，也不拿“协议栈”当睡前故事。它只教你几件要紧事：怎么把文件放对地方（别再塞进“桌面山”里了）；怎么找一款不偷你通讯录的软件；怎么避开那些披着“免费”外衣、实则满身广告跳蚤的“好心”程序；以及，哪儿能找到真正好用又不坑人的工具——这些事，学校不教，父母不懂，连隔壁老王都只会说“重启试试”。

但若你以为这教程只管你装个微信、删个垃圾，那可就小瞧它了。

如今的世界，AI能写情书、黑客能锁你冰箱、你家的灯泡可能正向某个遥远服务器汇报你的作息——这可不是危言耸听，这是周一的日常。

所以，这个教程也花些篇幅，聊聊生成式AI怎么“胡说八道又像真话”、网络安全为何比你家门锁还重要、云计算到底云了个啥、还有那些号称“万物互联”的小玩意儿，到底连的是便利，还是麻烦。
我们不说天书，只说人话；不画大饼，只点路灯——好让你在这数字洪流里，不至于被冲成个睁眼瞎的漂流瓶。

“零门槛、易理解、有深度”？哈！我们只是不想看着好人被科技耍得团团转罢了。

至于“与时俱进、开放共享”——那是因为我们相信：知识不该锁在付费墙后，而该像密西西比河的水一样，谁渴了都能喝上一口——只要别往里倒广告弹窗就行。
