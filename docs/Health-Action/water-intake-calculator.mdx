# 每日饮水量计算器

水是生命之源，正确的饮水量对维持身体健康至关重要。本计算器帮助您根据个人情况计算每日最佳饮水量。

## 基础计算公式

$$
V = W \times (30 \text{--} 35)
$$

**说明：**
- $ V $：每日建议饮水量（单位：ml）  
- $ W $：体重（单位：kg）  
- 系数范围 **30–35 ml/kg** 是一般健康成年人的推荐值（根据气候、活动量调整）

## 饮水量参考标准

### 不同人群每日建议饮水量

| 人群 | 建议饮水量 |
|------|-----------|
| 成年男性 | 2500-3000 ml |
| 成年女性 | 2000-2500 ml |
| 儿童 (4-8岁) | 1200 ml |
| 青少年 | 1800-2200 ml |
| 孕妇 | 2300-2500 ml |
| 哺乳期 | 2700-3000 ml |
| 老年人 | 1500-2000 ml |

### 特殊情况调整

| 情况 | 调整建议 |
|------|---------|
| 🏃 运动1小时 | +500-1000 ml |
| ☀️ 炎热天气 | +500-700 ml |
| 🤒 发烧/腹泻 | +500-1000 ml |
| ✈️ 飞机旅行 | 每2小时 +250 ml |
| 🏔️ 高海拔地区 | +500 ml |

:::caution 注意事项
- 心脏病、肾病患者应遵医嘱控制饮水量
- 过量饮水可能导致水中毒（低钠血症）
- 老年人口渴感觉可能减退，需主动补水
- 如有特殊健康状况，请咨询医生
