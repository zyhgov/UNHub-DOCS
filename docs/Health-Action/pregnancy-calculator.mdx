# 孕期计算器

专业的孕期计算工具，帮助准妈妈了解预产期、当前孕周、胎儿发育情况和重要产检时间。

## 预产期计算公式

### 内格莱氏法则（最常用）

$$
预产期 = 末次月经第一天 + 280天
$$

或使用简化公式：
- **月份**：末次月经月份 - 3（或 + 9）
- **日期**：末次月经日期 + 7

:::tip
💡 例如：末次月经为 3月10日，预产期为 12月17日
:::

:::info
内格莱氏法则（Naegele's rule）是计算预产期的标准方法，由德国产科医生法蓝瓷·卡尔·内格莱（Franz Karl Naegele）发明，因而得名。计算方法是根据女性最后月经周期的第一天，加上一年，减三个月，加上七天。因此，一般来说，预产期大约40个星期，若从授精开始，则为38个星期。
:::

## 孕期阶段概览

| 阶段 | 孕周 | 特点 |
|------|------|------|
| 🌸 **孕早期** | 1-12周 | 器官形成期，早孕反应，需补充叶酸 |
| 🌷 **孕中期** | 13-27周 | 胎动出现，进行大排畸检查 |
| 🌺 **孕晚期** | 28-40周 | 胎儿快速增长，准备分娩 |

## 重要产检时间

| 孕周 | 检查项目 |
|------|----------|
| 6-8周 | 确认宫内孕，B超检查 |
| 11-14周 | NT检查，建档 |
| 15-20周 | 唐氏筛查/无创DNA |
| 20-24周 | 大排畸（四维彩超） |
| 24-28周 | 糖耐量测试 |
| 28周后 | 胎心监护，2-4周一次 |
| 37周后 | 每周产检 |
