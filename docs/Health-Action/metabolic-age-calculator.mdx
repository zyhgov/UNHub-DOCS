# 代谢年龄计算器

**代谢年龄 (Metabolic Age)** 是基于基础代谢率评估的身体实际代谢状态对应的年龄，反映您的身体活力和健康水平。

## 核心概念

$$
A_{\text{met}} = f(\text{BMR}, L)
$$

其中：
- $ A_{\text{met}} $：代谢年龄（Metabolic Age）  
- $ \text{BMR} $：基础代谢率（Basal Metabolic Rate）  
- $ L $：生活方式因素（如运动、睡眠、压力等综合评分）

说明：
- **代谢年龄 < 实际年龄**：代谢状态良好 ✅
- **代谢年龄 = 实际年龄**：代谢状态正常 ➡️
- **代谢年龄 > 实际年龄**：代谢状态需改善 ⚠️

## 代谢年龄评估等级

| 代谢年龄 vs 实际年龄 | 评级 | 说明 |
|---------------------|------|------|
| 低 10 岁以上 | 🌟 卓越 | 身体代谢状态非常优秀 |
| 低 5-10 岁 | ⭐ 优秀 | 代谢健康水平很好 |
| 低 0-5 岁 | 👍 良好 | 代谢状态良好 |
| 高 0-5 岁 | 📊 一般 | 可通过生活方式改善 |
| 高 5-10 岁 | ⚠️ 偏低 | 需要关注代谢健康 |
| 高 10 岁以上 | 🔴 较差 | 建议积极改善 |

## 影响代谢年龄的关键因素

### 正面因素（降低代谢年龄）

| 因素 | 影响 |
|------|------|
| 💪 增加肌肉量 | 每增加1kg肌肉，每天多消耗50-100卡 |
| 🏃 规律运动 | 提升静息代谢率 5-10% |
| 😴 优质睡眠 | 调节代谢激素 |
| 🥗 均衡饮食 | 维持代谢平衡 |
| 💧 充足饮水 | 促进代谢反应 |

### 负面因素（增加代谢年龄）

| 因素 | 影响 |
|------|------|
| 🪑 久坐不动 | 降低肌肉量和代谢率 |
| 😰 长期压力 | 皮质醇升高影响代谢 |
| 🚬 吸烟 | 损害细胞代谢功能 |
| 🍺 过量饮酒 | 影响肝脏代谢 |
| 🌙 睡眠不足 | 代谢激素紊乱 |
