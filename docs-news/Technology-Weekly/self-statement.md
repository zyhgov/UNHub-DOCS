# 科技爱好者周刊

## 📌 项目简介

[https://github.com/ruanyf/weekly](https://github.com/ruanyf/weekly) 是由知名技术博主、《ES6 标准入门》作者 **阮一峰（Ruan Yifeng）** 维护的一个高质量中文技术周刊项目。

该仓库是 **《阮一峰的网络日志 · 科技周刊》** 的内容归档，每**周五**定期更新，旨在：

> **“记录每周值得分享的科技内容”**

内容覆盖广泛，包括但不限于：
- 编程语言与开发工具（如 JavaScript、Python、Rust、VS Code 等）
- 人工智能与大模型（AI、LLM、Agent、训练数据等）
- 软件工程与系统设计
- 创业、科技行业趋势、职场思考
- 开源项目推荐
- 数字生活、硬件、互联网文化
- 技术伦理、社会影响、未来预测

## 🔍 主要特点

1. **每周一期，长期坚持**  
   自 2019 年起持续更新，目前已发布 **370+ 期**（截至 2024 年 10 月），形成庞大的知识库。

2. **内容精选，观点独到**  
   不只是信息搬运，更包含阮一峰本人的点评、延伸思考和批判性分析。

3. **开放投稿**  
   欢迎读者通过 GitHub Issues 提交文章、软件或资源推荐，社区参与度高。

4. **附带“谁在招人”板块**  
   在讨论区提供 **免费程序员招聘帖服务**，帮助开发者对接工作/实习机会，深受技术圈欢迎。

5. **风格清晰，适合泛读与深度阅读结合**  
   每期通常包含 5–10 条精选内容，每条附有原文链接 + 中文摘要 + 作者观点。

## 🌐 如何使用？

- **在线阅读**：访问 [https://www.ruanyifeng.com/blog/weekly/](https://www.ruanyifeng.com/blog/weekly/)
- **订阅 RSS**：支持 RSS 订阅，便于聚合阅读
- **GitHub Star / Watch**：跟踪更新
- **参与社区**：提交 Issue 推荐内容或发布招聘信息
